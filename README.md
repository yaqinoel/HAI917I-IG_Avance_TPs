# HAI917I — Informatique graphique avancée

Personal coursework repository for the HAI917I course at Université de Montpellier.

## Projects

- `TP1_HPSS`: Hermite Moving Least Squares (HPSS) point-cloud projection.

## Setup

Clone the repository with its third-party dependencies:

```bash
git clone --recurse-submodules <repository-url>
```

For an existing clone, initialize them with:

```bash
git submodule update --init --recursive
```
